村里有个世代相传的绝活——**拼布画**。

别人画画用笔，他们家用碎布片拼。一张画裁成几十甚至上百个小方格，每个格子里填一块对应颜色的布，远看就是完整的图画。这门手艺传了上百年，规矩只有一条：**每块布的颜色，只能看它紧挨着的上下左右四块来定。**

老匠人周师傅是村里公认的第一把交椅。他拼的《秋收图》，近看每块布都平淡无奇，远看却层层叠叠、错落有致。收徒时，他总说一句话：“**布和布之间，只有挨着的才有关联。** 做拼布画，心里装着邻居就够了。”

徒弟们谨记师父教诲，一代代传下来，倒也佳作不断。

直到有个叫阿远的小徒弟，有一天突然问：“师父，如果左上角的天空和右下角的麦田颜色呼应，为什么不能直接比着调？”

周师傅瞪了他一眼：“隔那么远，风马牛不相及，看它作甚？”

阿远没再吭声，但心里一直搁着这个念头。

后来阿远离开村子，去了很远的地方游学。多年后他回来，带回一门奇怪的新手艺。他把画布切成同样大小的小方块，但做法完全不同——**他让每一块布同时参考画布上所有其他方块的颜色**，远的天、近的地、左的山、右的水，统统拿来一起比较，算出最合适的那个颜色再填进去。

第一幅作品出来，全村震惊。远山和近水的色调浑然一体，整幅画好像从同一个光源下长出来的。周师傅看了半晌，默默说了句：“**全局的眼光，确实厉害。**”

但问题很快来了。

阿远的新法子有个致命的毛病——**太能吃布了**。别人拼一幅画用一筐碎布，他用同样的法子要消耗十筐。村里布匹有限，阿远试了几次，拼出来的画要么颜色别扭，要么还不如周师傅的老作品顺眼。

村里人议论纷纷：“新法子华而不实，还是老师傅实在。”

阿远不服气，又埋头琢磨了半年，终于找到了症结。

他发现自己之前太死板了——把每一块布都当成完全独立的东西，忘了它们原本在画布上是有位置的。于是他在每一块布旁边悄悄别了一个小标签，上面写着它在画布上的坐标：第几行、第几列。有了这个标签，布块在比较颜色时就不会把左上角和右下角搞混了。

更妙的是，他还在所有布块前面额外加了一块特殊的白布——**这块布不参与拼画，它的颜色会跟着所有其他布块的变化而变，最终它呈现的颜色，就是整幅画的“总印象”**。别人问这幅画整体是什么感觉，看一眼这块白布就知道。

经过这番改进，阿远的新法子终于大成。只要有足够多的布匹供他反复试错，他拼出来的画在整体和谐度上，渐渐超过了周师傅的传世之作。

但村里布匹终究有限。大多数时候，阿远的画时好时坏，远不如周师傅稳定。周师傅那套“只看邻居”的老法子虽然格局小，但胜在省布、稳定，随便给几筐碎布就能拼出一幅像样的画来。

村里人慢慢明白了：**老法子省布，新法子费布；布少时老法子管用，布多时新法子惊艳。**

后来阿远和周师傅索性合开了一间画坊。遇到布匹充裕的大订单，就用阿远的全局法，拼出气势恢宏的长卷；遇到布匹紧张的小活儿，就用周师傅的邻里法，又快又好地交差。两种法子各得其所，村里拼布画的名声反而越传越远了。

多年后，阿远在笔记里写道：

“拼一幅画，有两种思路。一种是只看邻居——省布、稳定，但眼界有限；一种是看全局——费布、起伏大，但格局开阔。布多时全局法胜，布少时邻里法赢。**不是谁取代谁，而是各有用处。** ”

村里人不全懂他的话，但都知道：从那以后，村里出了两派匠人——**邻里派**和**全局派**。两派吵吵闹闹了许多年，却联手把拼布画这门手艺，推到了从未有过的高度。

------

**概念解释：Vision Transformer (ViT)**

Vision Transformer是Google在2020年提出的图像分类模型，它的核心思想是**把图像当成一系列“词”来处理**。传统卷积神经网络（CNN）靠一层层局部卷积核提取特征，而ViT直接用Transformer的自注意力机制，让每个图像块从一开始就能看到整张图。

**故事中的隐喻对应表**

| 故事元素                             | ViT / CNN 概念                                               |
| :----------------------------------- | :----------------------------------------------------------- |
| **周师傅的“只看邻居”**               | **卷积神经网络（CNN）的归纳偏置**——假设相邻像素关系最密切（局部连接性），且特征模式在图像任何位置都同样有效（平移不变性）。 |
| **阿远的“让每块布同时参考所有布”**   | **ViT的自注意力机制（Self-Attention）**——每个图像块（Patch）可以与序列中所有其他块直接交互，捕获全局依赖关系。 |
| **把画布切成小方块**                 | **图像分块（Patch Partition）**——将输入图像分割成固定大小的小块（如16×16像素），每个块相当于NLP中的一个“词”。 |
| **给布块别上坐标标签**               | **位置编码（Positional Encoding）**——因为Transformer本身不感知顺序，需要额外加入位置信息来保留图像块的空间结构。 |
| **额外的那块白布**                   | **CLS Token（分类标记）**——在输入序列前附加一个特殊标记，其最终输出状态用作整张图的全局表示，供分类头使用。 |
| **新法子“太能吃布”**                 | **ViT需要大量数据**——由于缺乏CNN那种内置的图像先验（归纳偏置），ViT必须从海量数据中自己学习空间关系和局部特征。 |
| **布少时老法子稳，布多时新法子惊艳** | **数据规模决定模型优劣**——中等数据集上ViT不如CNN；但当数据量足够大时，ViT的表现会超越CNN。 |
| **邻里派和全局派各有用处**           | **CNN与ViT各有适用场景**——CNN数据效率高、适合小数据集；ViT扩展性强、适合大数据和追求全局理解的场景。 |

这个故事想说的是：**看邻居有看邻居的稳，看全局有看全局的广。布少时邻里法保底，布多时全局法封顶。真正的进步，不是用一个取代另一个，而是让两种眼光各自去到该去的地方。**
